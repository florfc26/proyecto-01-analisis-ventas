# Proyecto 01 — Análisis de ventas | Comercial Argentina

## 1. Descripción del proyecto

Desarrollo de un dashboard interactivo en Power BI para analizar el comportamiento de las ventas de una empresa comercial ficticia llamada Comercial Argentina.

El objetivo es transformar los datos de ventas en información útil para la toma de decisiones comerciales.

## 2. Herramientas utilizadas

- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## 3. Indicadores analizados

- Ventas totales.
- Facturación por provincia.
- Facturación por producto.
- Filtros interactivos por provincia.

## 4. Principales resultados

- Facturación total: $4.700.000.
- Provincia líder: Córdoba ($1.680.000).
- Segundo lugar: Buenos Aires ($1.670.000).
- Producto líder: Notebook ($3.650.000).
- Producto con menor facturación: Mouse ($500.000).

## 5. Conclusiones

Notebook representa el principal producto en términos de facturación.

Córdoba registra el mayor volumen de ventas, aunque Buenos Aires presenta resultados muy similares.

Se recomienda desarrollar estrategias comerciales específicas por provincia y analizar oportunidades para incrementar las ventas de teclados y mouse.

## 6. Objetivo profesional

Este proyecto forma parte de mi portfolio de Data Analyst y demuestra habilidades iniciales de transformación de datos, modelado, creación de medidas DAX, visualización e interpretación de información.
